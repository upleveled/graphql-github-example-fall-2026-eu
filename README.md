# UpLeveled GraphQL Example (GitHub GraphQL API)

Example project demonstrating features of Apollo Client to query the existing GitHub GraphQL API.

This example is part of the curriculum for the [UpLeveled Full Stack Web Development Program](https://upleveled.io/full-stack-web-development-program).

![Screenshot of homepage, showing a header with links and page content](./screenshot.avif)

## Technologies

- [Next.js](https://nextjs.org/)
- [Apollo Client](https://www.apollographql.com/docs/react)
- [GitHub GraphQL API](https://docs.github.com/en/graphql/overview/about-the-graphql-api)
